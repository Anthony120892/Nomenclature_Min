# Nomenclature_Min 🎲

Application Streamlit pour travailler la nomenclature chimique avec deux dés.

## Lancer en local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Déployer sur Streamlit Community Cloud

1. Créer un dépôt GitHub.
2. Ajouter ces fichiers :
   - `app.py`
   - `requirements.txt`
   - `README.md`
3. Aller sur Streamlit Community Cloud.
4. Choisir le dépôt GitHub.
5. Indiquer comme fichier principal : `app.py`.
6. Déployer.
